# 最重要・最新のアイディア

## 設定のアイディア

- 情報伝達を副題として組み込み、暗号などをゲームに入れたい。
- 黒姫真理は、戸鎖続に対して天鷺羽音に近づいて情報を探ったり誘導するように指示し、燈ヶ丘高等学校に転校させる。
- 黒姫真理の最終目的は、天鷺善彦に関する何かにする。
- 奨励会に落ちてプロ棋士の夢を諦めた戸鎖続は黒姫真理と出会う。
- 戸鎖続は天鷺善彦に憧れて将棋を初めた。
- 黒姫真理はラスボスではなく、別で居るラスボスを倒そうとしている存在。ラスボスを倒すために羽音を利用しようとしていて、続はそれに協力している。
- 続は真理の指示で、羽音を成長させて最終的に協力しラスボスを倒そうとしている。
- ラスボスの正体は未定。天鷺善彦をラスボスにするのが有力かも。
- 真理からの指示は何らかの方法で突然届き、真理への報告は与えられている公開鍵に乗っ取って暗号化して送る。
- 真理は強力な電波妨害装置のようなものを持っており、最も効果的な場面で必ず使ってくるため、通信機器での情報伝達には頼れず、手紙などの原始的な通信方式に頼らざるを得ない。ラスボスは通信の傍受などできるようにすることで、通信機器に頼れなくする。
- 真理は物語中盤まで、羽音を天鷺善彦に対抗するための頭脳に育てるための行動と、天鷺善彦の組織の情報を探ったり妨害したりしている。
- 真理が羽音に暗号を復号させるのは、アナログな方法で羽音に安全に素早く情報を伝えられるようにするためと、敵組織の暗号を解読できるようにするため。
- 終盤では、真理の思考の一部を羽音が肩代わりして、高速で正確な推論をする。
- 黒姫真理の指示で、戸鎖続は羽音に接触。
- 真理は、自分の計画に羽音を利用できると考えて、最も観察と読みが優れている続を通して羽音が自分を追う過程かその先で、真理の目的を達成する、もしくは真理が知りたいことを明らかにするように誘導する。
- 天鷺善彦の娘であることを利用するか、羽音の能力を利用する。

## キャラクターメモ
- 羽音は読みが速いが、相手が打ちそうな手を予想したりはせず、機械的に読む。
- 真理は、性格などから相手が打ちそうな手を予想して確率が高い局面を深く読むため、効率が良い。
- 真理は、相手がどこまで読めるかを予想することで、罠に嵌めることができる。「相手は7手先までしか読めないだろうから、11手先まで考えた時に悪手になる手がある局面へ誘導しよう。」という感じ。
